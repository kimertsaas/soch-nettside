# SOCH – Nordic Concierge | GitHub Pages

Dette er den komplette nettsiden med forside, fire bysider og 16 topp-10-sider.

## Publiser gratis (uten eget domene)

1. Lag en gratis konto på https://github.com/.
2. Velg **New repository** og gi det navnet `soch-nettside`. Velg **Public** og opprett.
3. Velg **Add file → Upload files**. Last opp **innholdet i denne mappen** (ikke ZIP-filen som én fil). Sørg for at `index.html` ligger i roten, og at `assets/` følger med.
4. Gå til **Settings → Pages**. Under **Build and deployment**, velg **Deploy from a branch**, branch **main**, folder **/(root)**. Lagre.
5. Nettstedet publiseres på `https://DITT-BRUKERNAVN.github.io/soch-nettside/` etter noen minutter.

## Redigere innhold

- Enkel redigering: åpne den aktuelle `.html`-filen i GitHub, klikk blyanten (**Edit this file**), endre tekst, og velg **Commit changes**. GitHub Pages oppdateres automatisk.
- For bilder: last opp et nytt bilde i `assets/` og oppdater bildestien i HTML-filen. Ikke slett eller gi nytt navn til eksisterende filer uten å oppdatere referansene.
- For større redaksjonell oppdatering anbefales et eget CMS-oppsett. **Denne pakken har ikke et ferdig CMS/administrasjonspanel eller innlogging.** GitHub Pages er statisk hosting.

## Viktig

- HTML-filene inneholder mye innebygd CSS, JavaScript og bildedata for å bevare designet også ved direkte åpning. Unngå å redigere kode uten sikkerhetskopi.
- Innhold og topplister er redaksjonelle utkast. Verifiser fakta og rettigheter til bilder før kommersiell publisering.
- Eventuelle kontaktskjema/forespørselsknapper må kobles til en reell e-post eller skjematjeneste før lansering.
- GitHub Pages er gratis for offentlige repositorier, men et eget domene må vanligvis kjøpes separat.
